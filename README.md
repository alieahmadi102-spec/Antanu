# 🤖 آنتانو (ANTANU) — فاز ۱

هوش مصنوعی فارسی‌زبان با رابط وب، سیستم ثبت‌نام با کد ۵۰ رقمی، قفل یک‌دستگاهی و اشتراک ۱ تا ۴ ستاره.

**بدون نیاز به Ollama** — مغز هوش مصنوعی از طریق سرویس‌های ابری رایگان تأمین می‌شود.

---

## ۱) پیش‌نیاز

- فقط پایتون ۳.۱۰ یا بالاتر → https://python.org

## ۲) گرفتن کلید رایگان (یکی را انتخاب کنید)

| سرویس | کیفیت فارسی | ظرفیت رایگان (تقریبی) | مناسب برای |
|--------|:---:|---|---|
| 🟢 **Groq** (پیشنهادی) | خوب | ۳۰ درخواست/دقیقه — تا ۱۴,۴۰۰ درخواست/روز با مدل سبک | تعداد کاربر زیاد |
| 🔵 **Gemini** (گوگل) | **عالی** | حدود ۱,۵۰۰ درخواست/روز | بهترین کیفیت فارسی |
| ⚫ **GitHub Models** | خوب | فقط ~۵۰ تا ۱۵۰ درخواست/روز ⚠️ | تست و شروع |
| 🟣 **OpenRouter** | متغیر | محدود | مدل‌های متنوع |

### 🟢 Groq (پیشنهادی — سریع‌ترین)
1. ثبت‌نام در https://console.groq.com (رایگان، بدون کارت بانکی)
2. از بخش **API Keys** یک کلید بسازید
3. اجرا:
```bash
# ویندوز (CMD):
set ANTANU_PROVIDER=groq
set ANTANU_API_KEY=کلید-شما

# لینوکس:
export ANTANU_PROVIDER=groq
export ANTANU_API_KEY=کلید-شما
```
> مدل پیش‌فرض `llama-3.3-70b-versatile` است (باکیفیت، سقف ~۱۰۰۰ درخواست/روز).
> برای کاربران بیشتر، مدل سبک‌تر با سقف ۱۴,۴۰۰ درخواست/روز:
> `set ANTANU_MODEL=llama-3.1-8b-instant`

### 🔵 Gemini (بهترین فارسی)
1. کلید رایگان از https://aistudio.google.com/apikey
2. اجرا:
```bash
set ANTANU_PROVIDER=gemini
set ANTANU_API_KEY=کلید-شما
```

### ⚫ GitHub Models (با اکانت گیت‌هاب)
1. در گیت‌هاب: **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
2. در بخش **Permissions → Account permissions → Models** گزینه **Read-only** را فعال کنید
3. اجرا:
```bash
set ANTANU_PROVIDER=github
set ANTANU_API_KEY=توکن-گیت‌هاب-شما
```
> ⚠️ محدودیت روزانه GitHub Models کم است (~۵۰ تا ۱۵۰ درخواست در روز بسته به مدل) — برای تست عالی است ولی برای صدها کاربر کافی نیست. مدل را می‌توانید عوض کنید: `set ANTANU_MODEL=openai/gpt-4o` یا `deepseek/deepseek-r1` و...

### 🟣 OpenRouter
1. کلید از https://openrouter.ai/keys
2. اجرا:
```bash
set ANTANU_PROVIDER=openrouter
set ANTANU_API_KEY=کلید-شما
```

### 🔧 هر سرویس دیگر (پیشرفته)
هر سرویس سازگار با OpenAI (حتی مدل محلی) با دو متغیر قابل اتصال است:
```bash
set ANTANU_API_BASE=https://آدرس-سرویس/v1
set ANTANU_MODEL=نام-مدل
set ANTANU_API_KEY=کلید
```

## ۳) نصب و اجرا

داخل پوشه پروژه:
```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```
سپس در مرورگر: **http://localhost:8000**

## ۴) ورود ادمین

- نام کاربری: `admin`
- گذرواژه: `Antanu@1234`

⚠️ **حتماً قبل از استفاده واقعی عوضش کنید:**
```bash
set ANTANU_ADMIN_USER=مدیر_دلخواه
set ANTANU_ADMIN_PASS=گذرواژه_قوی
```
> ادمین فقط بار اول ساخته می‌شود؛ اگر قبلاً اجرا کرده‌اید فایل `antanu.db` را حذف کنید تا از نو ساخته شود.

## ۵) تنظیمات دیگر (اختیاری)

```bash
set ANTANU_ADMIN_CONTACT=آیدی تلگرام: @my_id   ← راه ارتباطی در صفحه خرید اشتراک
set ANTANU_MODEL=نام-مدل                        ← تعویض مدل
```

## گردش کار فروش اشتراک

1. کاربر وارد صفحه «خرید اشتراک» می‌شود و با شما (ادمین) تماس می‌گیرد.
2. بعد از پرداخت، در **پنل مدیریت ← تولید کد** یک کد ۵۰ رقمی با ستاره موردنظر می‌سازید و برایش می‌فرستید.
3. کاربر با آن کد ثبت‌نام می‌کند؛ کد می‌سوزد و حساب به همان دستگاه قفل می‌شود.
4. اگر کاربر گوشی/کامپیوترش را عوض کرد: پنل مدیریت ← «آزادسازی دستگاه».

## نکته مهم درباره ظرفیت

سقف درخواستِ سرویس‌های رایگان برای **کل سایت** است، نه هر کاربر. یعنی با Groq و مدل سبک، مجموع همه کاربران روزی ~۱۴,۴۰۰ پیام می‌توانند بفرستند. اگر کاربران‌تان زیاد شد:
- چند سرویس را ترکیب کنید (مثلاً Groq اصلی + Gemini پشتیبان)، یا
- به پلن پولی ارزان همان سرویس ارتقا دهید (کد هیچ تغییری لازم ندارد)، یا
- بعداً مدل را روی سرور خودتان اجرا کنید.
